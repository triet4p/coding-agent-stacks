# Example references

This directory contains grounded example images for the Scientific Systems Diagram Language.

These files are intentionally named with **stable, human-readable filenames** so the documentation can refer to them using relative paths.

## Files

| Figure role | File |
|---|---|
| Unified architecture / three-plane closed loop | `./unified-architecture.png` |
| Authority & timescale stack | `./authority_timescale_stack.png` |
| Specialist-first routing under uncertainty | `./specialist-first-routing.png` |
| Failure taxonomy → recovery → learning | `./failure-recovery-learning.png` |
| Experience flywheel / data economy | `./data-economy.png` |
| Core vs accelerator vs research option map | `./research-option-map.png` |
| Improvement escalation ladder | `./improvement-ladder.png` |
| Evaluation matrix | `./evaluation-matrix.png` |

## Intended usage

- `../DESIGN.md` references these examples at the design-system level.
- `../SKILL.md` references them as style and archetype anchors.
- Individual archetype files reference the relevant example through `../examples/...` relative paths.

These examples are not the ontology themselves; they are **instantiations** of the archetypes.
