# Strategic Map

## Archetype purpose

Use this archetype to position components, ideas, or investments in a 2D conceptual space.

---

## Primary example reference

`../examples/research-option-map.png`

---

## When to use this archetype

- when the key message is comparative positioning rather than causal flow;
- when two axes such as necessity vs maturity, or coverage vs reliability, organize the concept space;
- when "core vs accelerator vs research" should be shown without reducing it to a one-dimensional list.

---

## Canonical figure claim

"These components occupy different positions in a meaningful conceptual space, and the architecture should not treat them as equally necessary."

---

## Information structure

- two clearly named axes;
- positioned items or clusters;
- optional zone boundaries or labels;
- explanation of how to read the map.

---

## Mandatory elements

- explicit axis labels;
- a meaningful interpretation of each quadrant or zone;
- legible item placement.

---

## Optional elements

- grouped items;
- colored regions;
- maturity or risk annotation;
- supporting legend if multiple visual classes are present.

---

## Layout guidance

1. Choose one dominant reading direction.
2. Keep region boundaries explicit when groups matter.
3. Use muted semantic color coding from `../DESIGN.md`.
4. Keep node text compact and scan-friendly.
5. Include a legend if multiple edge or border semantics are used.

---

## Text guidance

- Prefer functional labels.
- Use secondary italic lines only when they add important nuance.
- Keep the title claim-oriented.
- Avoid overloading the figure with prose.

---

## Anti-patterns

1. using arbitrary axes;
2. packing too many items;
3. positioning items without clear rationale;
4. confusing a map with a ranking.
